02 · agentes

Traga o seu agente.

O Melinna lança executáveis, não importa SDKs. Cada agente é uma entrada num catálogo — acrescentar um novo é editar um JSON.

CClaude Code XCodex CLI GGemini CLI >PowerShell 7 >Windows PowerShell $Git Bash >Prompt de Comando $Bash %Zsh qualquer outro agente de CLI

03 · como funciona

Três passos até o primeiro agente.

01

Abra uma pasta

“Novo terminal” ou “Abrir workspace”. Qualquer pasta vira workspace e fica nos recentes.

02

Escolha a IA

O agente abre num terminal real, já na pasta certa, com modelo e modo padrão do catálogo.

03

Converse em paralelo

Abra quantos precisar, redimensione a grade e acompanhe todos de uma vez.
